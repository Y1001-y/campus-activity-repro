===== BUG-08 复现（真实输出，发生在 A10 发布活动页 type-check）=====
$ cd app && pnpm type-check
$ vue-tsc --noEmit
src/pages/activity/publish.vue(71,21): error TS7053: Element implicitly has an 'any' type because expression of type '0' can't be used to index type 'ChooseImageSuccessCallbackResultFile | ChooseImageSuccessCallbackResultFile[] | File | File[]'.
  Property '0' does not exist on type 'ChooseImageSuccessCallbackResultFile | ChooseImageSuccessCallbackResultFile[] | File | File[]'.
src/pages/activity/publish.vue(71,41): error TS7053: Element implicitly has an 'any' type because expression of type '0' can't be used to index type 'ChooseImageSuccessCallbackResultFile | ChooseImageSuccessCallbackResultFile[] | File | File[]'.
  Property '0' does not exist on type 'ChooseImageSuccessCallbackResultFile | ChooseImageSuccessCallbackResultFile[] | File | File[]'.
[ELIFECYCLE] Command failed with exit code 2.
退出码 = 2

===== 可复现指令 =====
1. 在 chooseImage 成功回调中直接写 res.tempFiles[0].size
2. cd app && pnpm type-check
3. 观察 TS7053

===== 原因 =====
uni-app 的 chooseImage 回调里 res.tempFiles 被声明为
ChooseImageSuccessCallbackResultFile | ... | File | File[] 的联合类型，
TypeScript 不允许用 [0] 索引一个可能是单对象/可能是数组的联合类型。

===== 解决 =====
先把 tempFiles 归一化为数组再取首项：
const files = Array.isArray(res.tempFiles) ? res.tempFiles : [res.tempFiles]
const size = (files[0] as { size?: number })?.size || 0
重跑 pnpm type-check 通过（退出码 0）。

===== 预防 =====
涉及 uni API 回调的联合类型返回值，先用 Array.isArray / 类型断言归一化再访问下标，
并把 type-check 纳入每次提交前检查。
